# 프론트엔드 검증 결과

- 현재 인증 정책을 포함한 프론트 테스트 총 74개 통과
- Vite 프로덕션 빌드 통과
- Chromium에서 동일한 모의 API 응답으로 원본 배포 번들과 추출본 비교
- 로그인: 원본 2단 레이아웃 유지, 가입·복구·소셜 로그인 절차 제거 적용
- dashboard: 원본과 추출본의 전체 페이지 픽셀 일치 (1440×1061)
- subscriptions: 원본과 추출본의 전체 페이지 픽셀 일치 (1440×1061)
- add: 원본과 추출본의 전체 페이지 픽셀 일치 (1440×1061)
- mobile: 원본과 추출본의 전체 페이지 픽셀 일치 (390×2256)
- 실제 브라우저에서 구독 추가 → CSRF 포함 등록 요청 → 저장 결과 목록 반영 확인
- 비교/저장 검증 중 브라우저 JavaScript 예외 없음

브라우저 캡처의 구독·금액은 시각/기능 검증용 모의 응답입니다. 앱에 시드 데이터나 로그인 우회를 넣지 않았습니다. 화면을 유지했는지와 프론트 요청 동작을 검증한 결과이며, 실제 Spring 서버/DB의 통합 성공을 의미하지 않습니다.

첨부 서버의 미구현 API와 인증 연결 조건은 SERVER-INTEGRATION.md를 확인하세요.

현재 로그인 화면은 `screenshots/login.png`에서 확인할 수 있습니다. 가입·복구 버튼의 부재와 이전 가입·복구·OAuth 주소에서 삭제한 API가 호출되지 않는지 브라우저로 확인했습니다.

구독 등록·수정 검증을 보완했습니다. 공백/100자 초과 이름, 비정수·음수·서버 정수 범위 초과 금액, 잘못된 결제일/기준일을 차단하고, 저장 실패 후 입력 유지·재시도·빈 저장 응답 처리를 검증했습니다.

이름·서식 정리 후 기본 server-dev 모드에서 CSRF 사전 요청이 없는지, 선택적 original 모드에서 CSRF 검사가 유지되는지, 백엔드 8080 연결 주소가 변경되지 않았는지 검증했습니다.

최종 정적 번들을 8080 HTTP 서버에서 열고 모의 API로 UUID 로그인, 사용자 헤더, CSRF 사전 요청 부재와 JavaScript 예외 부재를 확인했습니다. 실제 Spring 서버의 정적 경로 허용이나 JWT 통합 성공을 의미하지 않습니다.
