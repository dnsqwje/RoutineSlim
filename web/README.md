# RoutineSlim Web

첨부된 `RoutineSlim-App-dev`의 화면을 브라우저로 옮긴 프론트엔드입니다. 원본 앱의 색상 토큰, SVG 아이콘, 카드·폼·캘린더·차트와 하단 5개 탭을 재사용합니다. 데스크톱에서는 390px 앱 화면을 가운데 표시하고, 모바일에서는 화면 폭에 맞춥니다.

## 실행

Node.js 22.12 이상(검증: 24.19.0), npm을 사용합니다.

```sh
cd web
npm ci
npm run dev
```

웹 폴더 자체를 압축 해제했다면 해당 폴더에서 실행하세요. 터미널에 표시된 주소로 접속합니다. 백엔드 없이 실행할 수 있습니다.

```sh
npm run build       # TypeScript 검사 + 프로덕션 빌드
npm run preview     # dist 결과 확인
```

생성되는 `dist/`를 정적 호스팅에 배포할 수 있습니다. BrowserRouter를 사용하므로 `/calendar` 등으로 직접 접속할 때도 `index.html`을 반환하는 SPA fallback 설정이 필요합니다. Nginx에서는 `try_files $uri $uri/ /index.html;`을 사용합니다. `index.html`을 파일로 더블클릭해서 여는 방식은 지원하지 않습니다.

## 포함된 화면과 동작

- 온보딩 4단계, 로그인 화면, 로그인 유지·로그아웃
- 홈 요약·다가오는 결제·구독 전체 보기
- 구독 직접 입력: 필수값·금액·날짜 검사, 카테고리·결제 주기·결제수단 선택, 저장
- 이미지 파일 선택·카메라 입력, 파일 형식/10MB 제한 검사, 원본 미리보기, 결과 수정·구독 저장/업데이트
- 캘린더: 월 이동·확장·날짜별 결제 내역
- 통계: 월 이동·카테고리별 금액·도넛 차트, 저장한 구독과 연동
- 사용량 점검 → 정리 방법 선택 → 절감액 비교 → 정리 계획 저장
- 커뮤니티: 게시판·검색·서비스 필터·정렬, 글 작성·상세·댓글·참여 의사 기록
- 마이: 프로필·월 예산·알림 선호 일정 저장, 구독 목록 삭제, CSV 내보내기, 구독 JSON 백업·복원

원본과 비교하기 쉽도록 초기 구독 6개와 사용 기록, 캘린더 기준일(2026-10-11)은 첨부 앱의 시안 데이터를 유지합니다. 홈 총액은 실제 샘플 금액의 합계인 61,690원으로 계산합니다. 원본 디자인 이미지의 61,790원은 샘플 합계와 100원 차이가 있습니다.

## 데이터와 서버 연결 범위

기본값은 **체험 모드**입니다. 로그인 화면에 이를 표시하며, 입력한 아이디·비밀번호를 저장하거나 전송하지 않습니다. 구독·게시글·댓글·프로필·설정은 이 브라우저의 localStorage에 저장되어 새로고침 후에도 유지됩니다. 다른 기기/사용자와 공유되지 않습니다.

첨부 앱도 대부분 목업 데이터와 미연결 콜백을 사용합니다. 이 웹에서는 해당 화면과 흐름을 유지하며 브라우저 저장을 추가했습니다. 실제 계정 회원가입/비밀번호 재설정, 소셜 로그인, 푸시 발송, 생체 잠금, 다른 앱의 사용시간 수집, 모집자에게 참여 요청 전송, 실제 서비스 해지와 결제 중단은 구현되어 있지 않습니다. 해당 버튼에는 지원 범위를 안내합니다. 정리 계획 저장은 구독 해지를 실행하지 않습니다.

이미지 선택 후 체험 모드의 결과는 **실제 OCR 결과가 아닌 원본 앱의 예시**이며 화면에 명시합니다. 직접 수정한 값을 저장할 수 있습니다.

첨부 Spring 서버가 준비되어 있으면 `.env.example`을 `.env.local`로 복사하고 `VITE_AUTH_MODE=server`로 바꾼 뒤 개발 서버를 재시작하세요.

```sh
API_PROXY_TARGET=http://localhost:8080 npm run dev
```

이 모드에서 연결하는 API는 다음 두 가지입니다.

- `POST /auth/login`: `{memberName, memberPassword, keepLoggedIn}` → 회원 UUID
- `POST /api/v1/subscriptions/scan`: `X-Member-Id`, multipart `image` → 인식 초안

로그인 실패 시 이동하지 않고 오류를 표시합니다. 구독·커뮤니티·프로필의 서버 CRUD는 아직 연결하지 않았으며 두 모드 모두 로컬에 저장합니다. 서버 모드에서도 로그인 화면에 이를 표시합니다. 실제 Spring 서버/DB/OCR 자격증명은 이 프론트엔드에 포함하거나 실행하지 않았습니다. 첨부 서버의 임시 UUID 인증 규약을 따르며 JWT 인증을 구현했다고 가정하지 않습니다.

개발 프록시는 Vite 개발 서버에서만 동작합니다. 운영 배포는 동일 출처의 `/auth`, `/api` 역방향 프록시를 구성하거나 `VITE_API_URL`과 백엔드 CORS를 설정해야 합니다. `VITE_` 변수에는 비밀키를 넣지 마세요.

## 브라우저 검증

```sh
# Chromium이 설치되어 있으면 경로를 지정합니다.
CHROMIUM_PATH=/usr/bin/chromium npm test
# 다른 환경에서는 Playwright 브라우저를 설치하고 실행 경로를 지정합니다.
npx playwright install chromium
```

`playwright.config.ts`의 기본 경로는 이 환경의 `/usr/bin/chromium`입니다. 자동화 테스트는 실제 브라우저에서 레이아웃·탭 이동, 구독 저장 후 홈/캘린더/통계 반영, 새로고침 유지, 게시글·댓글, 이미지 선택과 예시 표시, 설정·CSV와 정리 계획 등을 검증합니다. 실제 서버 연동은 이 검증 범위에 포함되지 않습니다.

## 구조

- `src/features/`, `src/components/`, `src/theme/`: 첨부 앱에서 재사용한 화면·컴포넌트·디자인 토큰
- `assets/`: 원본 앱 SVG와 이미지
- `src/app/`: 화면별 이벤트 연결
- `src/web/`: 웹 라우팅·포털·브라우저 저장·모바일 비율 레이아웃
- `tests/`: Playwright 기능 검증

React + TypeScript + Vite + React Native Web를 사용합니다. 모바일 화면을 다시 그리지 않고 재사용하기 위해 라우팅·안전 영역·그라데이션·SVG의 웹 어댑터를 제공합니다. 원본 라이선스는 `LICENSE`에 보존했습니다.
